How to Use TRIVORA

1. Enter Village and Survey Number

Start by entering the village name where the land is located and the survey number assigned to the property.

2. Understand Risk Levels

Low Risk: No active cases
Medium Risk: 1-2 ongoing cases
High Risk: 3+ active cases

3. Review Case Details

Click on any case to view detailed information including case type, parties involved, and current status.

4. Set Alerts

Enable notifications to receive updates when new court cases are filed for a property.

5. Supported Languages

TRIVORA supports search in Tamil and English. You can use voice input to search hands-free.
